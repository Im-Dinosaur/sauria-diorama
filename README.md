# SAURIA — A living prehistoric world

현재 앱은 300m 기준의 강·숲 디오라마와 7종 32개체, 평화로운 세계·빙하시대·Ember 모드로 구성됩니다. 승인된 티라노사우루스 보정본 3마리를 맵에 적용했고, 성체 몸길이 22m·12m·9m 비율과 고정 길이 관절의 음수 자세를 사용합니다.

Node.js 22.12 이상(`.nvmrc`: 검증한 버전)에서 `npm ci`, `npm run dev`로 실행합니다. 검사는 `npm run verify`, 배포 빌드는 `npm run build`입니다. 클라우드 미리보기에서는 `npm run dev -- --host 0.0.0.0`을 사용합니다.

프로젝트 상태·채팅별 인계와 모델 출처는 [클라우드 인계 문서](docs/cloud-handoff.md), 지도 구성은 [지형 문서](docs/reference-map.md)를 참고하세요.

아래는 초기 EMBER 프로토타입부터의 제작 기록이며 현재 앱과 다른 이전 구성도 포함합니다.

# EMBER — A world on the edge (archive)

Vite + React + TypeScript 기반의 인터랙티브 화산섬 디오라마입니다. Three.js, React Three Fiber, Drei, React Postprocessing, Leva를 사용합니다.

## 실행

Node.js 22 이상에서:

```sh
npm ci
npm run dev
npm run build
npm run verify
```

`npm run preview`는 빌드 결과를 로컬에서 확인합니다.

## 조작

- 장면 드래그: 카메라 회전. 자동 회전, 관성, 팬, 휠 줌은 사용하지 않습니다.
- 호버와 용암 클릭: 카메라와 지형에 영향 없음.
- 재생/정지 버튼 또는 본문에 포커스가 있을 때 Space: 모든 환경·공룡 애니메이션 정지/재개.
- Perspective / Top view / Side view: 세 시점. 원형 화살표: 기본 시점 복원.
- 슬라이더 아이콘: Leva 환경 패널(용암 밝기, 화산재, 메테오).
- About / Explore: 장면 설명. Esc: 패널 닫기.

## 검증

경로당 1,440개 지점, 지상 생물 간 서로 다른 시간 조합 2,073,600개를 검사했습니다. 모델 전체를 감싸는 보수적인 수평 반경을 사용합니다. 결과의 단위는 장면 단위입니다.

| 항목 | 최소 간격 |
| --- | ---: |
| 블록 벽 | 0.44000 |
| 지상 생물–장애물 | 0.07558 |
| 서로 다른 지상 이동 경로 | 0.53378 |
| 공중 생물–지형/소품 | 1.46373 |
| 지상 생물 몸통–지형 | 0.30780 |
| 발 지면–용암 수면 | 0.26400 |

발은 보이는 지형과 동일한 삼각형의 중위 좌표 높이를 매 프레임 사용합니다. 검증 수치는 이산 표본의 최솟값이며, 임의의 새 소품이나 경로 추가 후에는 `npm run verify`를 다시 실행해야 합니다.

브라우저에서 호버 이벤트 40회 후 카메라 변화 0, 용암 클릭 후 카메라 변화 0, 정지 중 시간 변화 0, 드래그 후 카메라 변화 발생을 확인했습니다. 초기 버전 검사 대상 414개 메시에서 부드러운 음영 0, 투명 효과의 그림자 0, 내부 텍스처 0을 확인했습니다. 6단계별 기본·측면·상부 캡처를 별도로 보관했습니다.

품질 단계는 ULTRA → BALANCED → ECO 방향으로만 내려갑니다. 렌더 픽셀 상한은 각각 1,900,000 / 1,300,000 / 850,000입니다. 고품질에서 MSAA는 0이고, Bloom·DOF·AO는 가로·세로 절반 해상도로 실행합니다. 단계 하향 시 모델, 용암 시계, 카메라를 다시 생성하지 않습니다.

개발 환경의 2560 × 1600 브라우저에서 실제 렌더 버퍼 1,898,127픽셀, 약 177 FPS를 관찰했습니다. 이는 현재 테스트 컴퓨터에서의 측정이며 실제 Retina 노트북 GPU에서 60 FPS를 검증한 결과는 아닙니다. 해당 장치 실측이 남아 있습니다. 390 × 844 세로 화면도 확인했습니다.

## 재현 및 에셋

- `?stage=1`부터 `?stage=6`까지 각 제작 단계의 누적 구성을 표시합니다.
- 개발 모드의 `?qa=1`에서 호버 입력 검증 버튼이 표시됩니다. 배포 빌드에는 이 버튼이 없습니다.
- 모든 생물, 지형, 바위와 소품은 코드로 생성했습니다. 외부 모델은 사용하지 않았습니다.
- 책상에만 [Poly Haven — Wood Table Worn](https://polyhaven.com/a/wood_table_worn)의 CC0 사진 기반 PBR 색상·OpenGL 노멀·거칠기 맵을 사용합니다. 나머지 장면은 텍스처가 없습니다.
- 이 예외는 원문의 사진 기반 책상 요구와 전체 텍스처 금지 요구를 함께 반영하기 위한 해석입니다.
- 용암은 물리 유체 솔버 대신 절차적 셰이더로 끓는 균열과 기포를 표현합니다. 블록과 수면의 외곽 정점은 고정입니다.
- 폰트는 Google Fonts의 DM Sans·Manrope이며 네트워크 불가 시 Arial로 대체됩니다.

## 2026-10-17 수정

- 티라노사우루스와 트리케라톱스 크기 50% 증가, 프테라노돈 약 38% 증가.
- 분할 장갑판, 통풍구, 관절 허브, 노출된 유압 실린더, 발톱, 날개 보강대 추가. 모든 모델은 절차적 형상과 평면 음영을 유지합니다.
- 육지 면적 36.60% 확장. 구·신 지형을 동일한 0.03 간격으로 표본화해 용암 수면 위 면적을 비교했습니다. 기존 화산 사면도 포함합니다.
- 용암 윗면과 옆면 모두 alpha 1이며, 내부 소품이나 바닥이 비치지 않습니다. 표면은 이미지 텍스처 없이 다중 노이즈 난류·냉각 껍질·열기·미세 반사를 계산합니다. 외곽 정점은 고정입니다.
- 시작 6초 후 첫 분출, 이후 26초마다 반복합니다. 화산 불꽃·분출 입자·연기가 솟은 뒤 메테오 3개가 시간차로 용암 바다에 떨어지고 파문이 사라집니다. 공통 시뮬레이션 시간을 사용해 정지/재생이 모두 동기화됩니다.
- `src/world/eruption.ts`는 순수 시간 함수로 분출 주기를 제공합니다. 별도 구조 변경 없이 기존 Weather와 용암 훅에서 사용합니다.
- 확대된 발바닥의 모서리와 보행 위상까지 검사한 지면 오차는 0입니다. 당시 분출 입자의 벽 최소 간격은 0.80448이었습니다. 최신 분출 수치는 아래 연기·폭발 개선 항목을 참조합니다.
- 변경 단계 5회 × 기본·측면·상부 캡처 15장을 `../qa-revision/`에 보관했습니다. 빌드 및 경로 검증 통과. 실제 Retina 노트북 GPU의 실측은 수행하지 않았습니다.
- 개발 모드 `?qa=1`의 Preview eruption 버튼으로 8.25초 분출 장면을 재현합니다. 배포 빌드에는 QA 버튼이 포함되지 않습니다.

## 용암 흐름과 수면 생물 추가

- `src/world/lavaFlows.ts`에서 지형을 따라가는 두 경로를 정의합니다. 전면·후면 흐름은 모두 바다 높이까지 이어지며, `src/scene/LavaFlows.tsx`가 하류 방향의 난류·밝은 중심부·식은 껍질을 표현합니다. 표면과 블록의 외곽은 고정입니다.
- `src/scene/LavaBoiling.tsx`는 팽창하는 기포, 터지는 테두리, 두 겹 파문과 탄도 불똥을 인스턴싱으로 그립니다. 고정 크기의 24개 이벤트 풀을 재사용하며 위치는 매번 새로 고릅니다. `src/shaders/lavaNoise.ts`의 절차적 무늬를 바다·흐름·기포가 공유합니다.
- `src/world/lavaEvents.ts`는 기포와 수면 공룡의 시간·위치를 계산합니다. 첫 공룡은 12초에 등장하고, 22초 간격으로 두 위치를 번갈아 사용합니다. 등장부터 잠김까지 6.8초이며 동시에 하나만 보입니다.

## 연기와 화산 폭발 개선

- `src/scene/VolcanicSmoke.tsx`와 `src/world/volcanicSmoke.ts`가 68개 연기 덩어리를 한 번의 인스턴스 드로우로 그립니다. 절차적 밀도 무늬, 부드러운 가장자리, 평면 법선 조명, 분화구의 열기 반사를 사용합니다. 카메라 깊이 순서로 인스턴스를 정렬해 회전 시 겹침이 안정적으로 보입니다.
- 평상시에는 좁은 연무가 계속 올라갑니다. 분출 시에는 재 구름이 빠르게 솟아 넓게 퍼지고, 폭발이 끝난 후에도 남아 천천히 흩어집니다. 이미지 텍스처나 외부 모델은 추가하지 않았습니다.
- `src/scene/VolcanoEruption.tsx`는 세 갈래의 난류 분출 기둥, 세 차례에 나눠 발사하는 화산탄 120개, 불꽃 꼬리 480개, 순간적인 조명 변화를 처리합니다. 기존 26초 주기 및 메테오와 동기화됩니다. 카메라는 흔들리지 않습니다.
- `src/world/eruption.ts`의 동일한 탄도 함수를 렌더링과 검증에서 함께 사용합니다. 모든 새 효과는 기존 재생/정지 시간을 사용하고, 그림자를 만들지 않습니다.
- `scripts/verify-volcano.ts`는 0.02초 간격으로 연기 48,861개 표본과 화산탄·꼬리 53,824개 표본을 검사합니다. 최소 블록 경계 간격은 연기 0.56311, 화산탄·꼬리 0.85673이며, 화산탄·꼬리의 최소 지형 간격은 0.05471입니다. 단위는 장면 단위입니다.
- 기존 지상 공룡 경로 간 최소 간격 0.53378, 장애물 간격 0.07558, 발바닥 지면 오차 0을 유지합니다. `npm run verify`는 보행·용암·분출 검증을 모두 실행합니다.
- 기본·측면·상부의 연기 및 폭발, 폭발 후 연무 캡처는 `../qa-volcano/`에 있습니다. 개발 모드 `?qa=1`의 Ignition / Preview eruption / Afterglow 버튼으로 각 단계를 재현합니다. 이 버튼은 배포에 포함되지 않습니다.
## 메테오 충돌과 용암 표면 흐름 개선
