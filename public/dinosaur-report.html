공통 제작 방식

형상단면을 곡선으로 연결한 연속 곡면과 세부 형상을 코드로 생성합니다. 삼각형 인덱스와 부드러운 법선을 유지하고, 종마다 머리·체형·발·꼬리·장식 구조를 다르게 구성했습니다.
피부·재질종마다 1024×1024 색상·OpenGL 노멀·거칠기 맵을 절차적으로 생성했습니다. 큰 색 띠와 배색은 정점 색상으로 입히고, UV에는 반복 가능한 미세 비늘 무늬를 사용합니다. 사진 스캔이나 고유 4K UV 페인팅은 사용하지 않았습니다.
리깅Three.js SkinnedMesh + 실제 본 계층입니다. 골반·가슴·목·머리·아래턱·다리·발·꼬리, 익룡의 날개를 제어하고 정점 가중치를 정규화했습니다. 육상 개체의 두 관절 다리는 지면 높이를 따르는 IK를 사용합니다. 수각류 앞팔과 손가락은 현재 독립 제어 본 없이 가슴에 결합돼 있습니다.
동작공유된 자세 계산기를 실시간 행동에 연결하고 24fps 키프레임 클립으로도 베이크했습니다. 동작 전환은 0.24초 동안 혼합합니다. 보행 위상은 실제 이동 거리를 기준으로 진행하고 정지 상태에서는 대기 자세를 사용합니다.

생활 행동을 선택하는 알고리즘

상태 선택갈증·먹이 욕구·피로 값을 갱신하고 먹이 활동, 음수, 휴식, 탐색을 선택하는 우선순위 상태 머신입니다. 재난은 현재 먹이·음수 상태를 중단합니다. 행동 시간과 무작위 시드는 재현할 수 있습니다.
자원 접근현재 지형의 수면과 마른 강둑을 검사한 250개 접근 후보를 사용합니다. 스피노사우루스는 강둑에서 주둥이를 수면으로 내밀고, 브라키오사우루스는 접근 가능한 나무 주변으로 이동합니다.
이동·회피A* 경로 탐색, 지면·나무·바위 검사와 주변 개체 분리 조향을 결합했습니다. 초식동물은 티라노가 가까우면 회피하거나 방어합니다. 트리케라톱스와 용각류의 느슨한 결속은 디오라마를 위한 행동 가정입니다.
먹이 탐색육식동물은 독립적으로 목표 주변에 접근하고 주변을 살핍니다. 실제 먹이 사망·개체 소모·번식이 있는 먹이망은 구현하지 않았습니다. 욕구 값은 활동을 분산시키는 추상 값이며 생리학 모델이 아닙니다.
비행프테라노돈은 안전 고도에서 날갯짓과 활공을 전환합니다. 현재 지상 보행·착륙·이륙·물고기 포획은 포함하지 않았습니다.
